# Интеграция Zagotovka-M с Home Assistant

Прошивка сама публикует устройства и сущности через MQTT Discovery
(модуль `Core/Src/ha_discovery.c`). Ручной настройки в Home Assistant не нужно.

## Требования

- Home Assistant с интеграцией MQTT. Брокер: встроенный в прошивку или внешний.
- Home Assistant 2025.10 или новее для заранее известных entity_id
  (параметр `HA_ENTITY_IDS`, см. ниже). Сущность `event` требует версию 2023.8 или новее.
- В веб-интерфейсе Zagotovka включен Discovery (`check_ha_disc`) и задан TX-топик.

## Что создается

Основное устройство **Zagotovka - M** (область "Zagotovka"). На его странице
есть версия прошивки и ссылка на веб-интерфейс контроллера.

Каждая физическая кнопка и каждая Zigbee-кнопка - отдельное устройство, привязанное
к основному (область "Zagotovka Buttons"). В нем три кнопки "Нажать" и одно событие.

| Что | entity_id |
|---|---|
| Выключатель | `switch.zagotovka_sw<ID>` |
| ШИМ | `number.zagotovka_pwm<ID>` (`light.` или `fan.` при другом `HA_PWM_TYPE`) |
| DS18B20 | `sensor.zagotovka_t<серийник строчными>` |
| DHT22 | `sensor.zagotovka_dht<ID>_t` (температура), `_h` (влажность) |
| Кнопка: нажатие | `button.zagotovka_bt<ID>_s` (click), `_d` (double click), `_l` (long press) |
| Кнопка: событие | `event.zagotovka_bt<ID>` |
| Охрана (физический пин) | `event.zagotovka_sec<ID>` |

`<ID>` - ID пина из веб-интерфейса Zagotovka. У Zigbee-кнопок ID продолжают нумерацию
после последнего физического пина.

## Настройки в коде

- `HA_ENTITY_IDS` (в `ha_discovery.c`, по умолчанию 1): выдавать заранее известные
  entity_id через `default_entity_id`. Для Home Assistant старше 2025.10 поставьте 0,
  иначе он отклонит конфиги с неизвестным ключом.
- `HA_PWM_TYPE` (в `ha_discovery.h`): тип сущности для ШИМ. 0 - number, 1 - light, 2 - fan.

## Как работают кнопки

- Нажатие в Home Assistant выполняет те же действия, что заданы для кнопки в веб-интерфейсе
  (колонки SINGLE CLICK, DOUBLE CLICK, LONG PRESS). Если колонка пустая, ничего не произойдет.
- Zigbee-кнопка попадает в Home Assistant, если слот занят, включен и имеет роль TRIGGER.
- Событие `event` приходит в Home Assistant только если у кнопки задано действие на этот
  тип нажатия.
- Команда для нажатия: `<rx-топик>/button/id=<ID>/single_click` (также `double_click`, `long_press`).

## Что нужно знать

- `default_entity_id` действует при первом создании сущности. У уже созданных сущностей
  id не меняется: удалите устройства Zagotovka в Home Assistant (Настройки - Устройства -
  меню - Удалить), прошивка создаст их заново с новыми id.
- Область устройству назначается, только если оно еще не лежит ни в какой области.
- Если у вас несколько контроллеров Zagotovka, Home Assistant добавит к повторяющимся
  id суффиксы `_2`, `_3`.
- Полная выдача конфигов занимает до 30-35 секунд при сотнях кнопок. Она повторяется
  при изменении состава устройств (добавили, удалили, переименовали датчик или кнопку)
  и когда Home Assistant присылает статус online.
- Удаленные датчики, кнопки и пины прошивка стирает из Home Assistant сама
  (пустым конфигом). Серийники DS18B20 помнятся только до перезагрузки контроллера.
- Не поддерживается: охрана через Zigbee, диагностические сенсоры (аптайм, память).
- Порядок блоков на странице устройства в Home Assistant задается самим Home Assistant
  и из прошивки не меняется. Для удобной работы используйте дашборд.

## Дашборды

В репозитории два готовых файла:

- `zagotovka_dashboard.yaml` - автоматический дашборд. Нужна карточка `auto-entities`
  (ставится через HACS). Подхватывает все сущности `zagotovka_*` сам.
- `zagotovka_dashboard_core.yaml` - на стандартных карточках, без HACS. Список сущностей
  нужно один раз отредактировать под свой проект (шаблон имен в шапке файла).

Установка: Настройки - Дашборды - Добавить дашборд - Новый дашборд с нуля, затем
карандаш - меню (три точки) - "Сырой редактор конфигурации", вставьте файл целиком.
Без собственного дашборда все сущности группируются на стандартном экране "Обзор"
по областям "Zagotovka" и "Zagotovka Buttons".

## Если что-то не появилось

- Проверьте, что в Home Assistant включена интеграция MQTT и что контроллер подключен к брокеру.
- Откройте Настройки - Устройства и службы - Объекты, введите "zagotovka": все id должны быть там.
- Сущности "недоступны": контроллер выключен или не публикует статус `<tx>/status`.
