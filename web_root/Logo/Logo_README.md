Zagotovka Mongoose: логотип в сайдбаре
В проекте
файлы: `main.js`, `index.html` и `logo.css`.
Все картинки встроены в `logo.css`.
Дальше обычная сборка `vite build` и упаковка в `packed_fs.c`.

 Настройки (самое начало logo.css, блок `.zl`)
- `width: 160px;` размер логотипа.
- `--zl-glint: 3;` время одного прохода блика в секундах, это и есть скорость луча (меньше значит быстрее).
- `--zl-beam-w: 18;` ширина луча в процентах от ширины логотипа (8 тонкий, 30 широкий).
- `--zl-beam-skew: -24deg;` наклон луча (0deg вертикальный).
- `--zl-beam-power: 1;` яркость луча от 0 до 1.
- `--zl-beam-ease: 0;` профиль скорости: 0 постоянная скорость, 1 медленно в начале и конце, быстро в середине.
- `--zl-pause: 0.2;` пауза в конце цикла, секунды 
Цикл считается так: 'время блика + 2,8 с (блок Mongoose) + пауза'. Значение по умолчанию 0,2 сохраняет прежний цикл ровно в 6 секунд, так что без ваших правок поведение не изменится.

Примеры для блика за 3 секунды:
| Нужный цикл | `--zl-glint` | `--zl-pause` |
|---|---|---|
| 6 с | `3` | `0.2` |
| 7 с | `3` | `1.2` |
| 9 с | `3` | `3.2` |
| 11 с | `3` | `5.2` |

Если вам нужен ровно «блик раз в N секунд», пауза считается так: `--zl-pause = N − 2,8 − --zl-glint`. 
Например, для N = 11 и блика за 3 секунды выходит 5,2.

Я проверил в Chromium, что при значениях 3 / 0,2, 3 / 5 и 2 / 0,2 длительность цикла получается 6, 10,8 и 5 секунд, а во время паузы блик за правым краем и Mongoose скрыт.
Mongoose от настроек блика не зависит: появляется 0,7 с, держится 1,5 с, гаснет 0,6 с, пауза 0,2 с.
Полный цикл = время блика + 3 с.

Темы
Светлая тема: тёмный металлический логотип. Тёмная тема: серебристый. Переключение по `data-theme`.
Фавикон ОТКЛЮЧЕН заглушка в `index.html`.

Вес
После сборки CSS около 15 КБ в gzip.
Итоговый прирост около 11 КБ при свободных ~14 КБ в банке (оценка по map-файлу), запас небольшой.
Анимация использует `@property`: нужен Chrome 85+, Safari 16.4+, Firefox 128+. В старых браузерах покажется статичный логотип без Mongoose.
